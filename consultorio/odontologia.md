## **HISTORIA CLÍNICA - ODONTOLOGÍA**

Para firmar el consentimiento desde el consultorio, prepara primero el móvil.

<details><summary class="text-primary">Preparar el móvil para recibir firmas</summary>
<p>Deja el celular en espera antes de solicitar la firma desde el consultorio.</p>
<p><b>1. Validar el acceso en Logis</b></p>
<p>En la aplicación web abre el menú <b>Terceros</b> y luego <b>Terceros Auxiliares</b>.</p>
<p><img src="/app/img/ayuda/firma-terceros-auxiliares.png" alt="Menú Terceros, opción Terceros Auxiliares" style="max-width:100%;border:1px solid #e4e7eb;border-radius:8px;"></p>
<p>Abre el dispositivo y confirma el <b>Usuario</b> y la <b>Contraseña</b>. El <b>Estado</b> debe estar activo. El usuario de ingreso es el nombre, un punto y el código de la empresa que aparece junto al campo. Ejemplo: <b>firma.consultorios</b>.</p>
<p><b>2. Iniciar sesión en el móvil</b></p>
<p>En el celular abre <a href="https://firma.logis.com.co" target="_blank">https://firma.logis.com.co</a>.</p>
<p><img src="/app/img/ayuda/firma-login.jpg" alt="Pantalla de ingreso de Logis Firma" style="max-width:100%;border:1px solid #e4e7eb;border-radius:8px;"></p>
<p>En <b>Usuario.establecimiento</b> escribe el usuario con el código de la empresa, ingresa la contraseña y pulsa <b>Ingresar</b>.</p>
<p><img src="/app/img/ayuda/firma-credenciales.jpg" alt="Credenciales de ingreso en el móvil" style="max-width:100%;border:1px solid #e4e7eb;border-radius:8px;"></p>
<p>El celular queda en <b>Esperando Documento para firmar</b>. Déjalo en esa pantalla para recibir las solicitudes de firma.</p>
<p><img src="/app/img/ayuda/firma-espera.jpg" alt="Pantalla en espera de un documento para firmar" style="max-width:100%;border:1px solid #e4e7eb;border-radius:8px;"></p>
</details>
